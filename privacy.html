Signal Dashboard私隱政策服務條款

私隱政策

本政策說明 Signal Dashboard 桌面程式如何處理已連接的發布商報表。

Google 帳戶資料

連接 AdMob 時，程式只申請 admob.report 權限，用以識別發布商帳戶及報表時區，讀取 App 識別碼、名稱、日期和預估廣告收益。程式使用這些資料來顯示報表、進行每日同步及核對後台金額。

保存及傳送

Google 發出授權後，桌面程式透過 Windows 加密保存更新權杖及裝置憑證。同步時，程式向 Google 取得報表，並把報表及對帳結果傳送至已配置的 Supabase 專案。桌面程式從該專案讀取報表，在記憶體中顯示。公開說明頁不會顯示帳戶報表。

停止存取及刪除

你可以在Google 帳戶的第三方連線設定移除 Signal Dashboard，停止日後讀取 AdMob 報表。撤銷授權後，已同步的資料仍保存在 Supabase。帳戶持有人可以聯絡下方電郵，要求刪除已保存的報表及對帳資料。

Signal Dashboard 使用 Google API 所取得的資料，以提供上述報表及對帳功能，並遵守 Google API Services User Data Policy，包括 Limited Use 要求。
